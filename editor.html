Elephant Mod: a free Scratch mod

Elephant Mod is a free, elephant-themed Scratch mod. It is a block-coding editor that runs in your browser, so kids and beginners can build games, animations and stories with no download or sign-up.

What you can do

  • Drag and drop blocks to code games, just like Scratch.
  • Use the built-in Camera extension with camera sensitivity blocks for mouse-look and follow cameras.
  • Start with an elephant sprite and an elephant-colored block palette.
  • Runs fast: projects are compiled to JavaScript, thanks to TurboWarp.

Elephant Mod is a mod of PenguinMod, which is a mod of TurboWarp, which is a mod of Scratch. Source code: github.com/imnmo/elephant-mod.
